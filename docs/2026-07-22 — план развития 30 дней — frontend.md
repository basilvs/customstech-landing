# План развития на 30 дней — фронтенд

**Дата плана:** 2026-07-22

---

## Вектор
Фронтенд.

## Проект
Продуктовый лендинг **CustomsTech**.

## Для кого
Таможенные брокеры, логисты, отделы ВЭД и руководители компаний, которые хотят автоматизировать рутину декларирования, отчётности и публикации новостей.

## Сценарий
Посетитель заходит на лендинг → видит, какие задачи решает CustomsTech → читает примеры и кейсы → нажимает CTA «Получить демо» или «Запустить в Telegram-боте» → оставляет контакт.

## Блоки решений
1. **Автопостинг — лента новостей.** Автоматическая публикация актуальных новостей ВЭД и законодательства в VK/Telegram/MAX на лендинге.
2. **Подготовка документов для декларирования и электронный обмен документами с таможенными органами.** Сбор, проверка и передача документов в электронном виде.
3. **Отчёты по ДТ.** Статусы, копии документов с отметками таможни, формализованные документы для бухгалтерии, презентации для руководства.

## Проверка результата
- Открыть лендинг в браузере, проверить адаптивность (320 px, 768 px, 1440 px).
- Запустить Lighthouse: цель — Performance ≥ 90, Accessibility ≥ 95.
- Проверить валидатор HTML и отсутствие критичных ошибок в консоли.
- Сделать скриншоты для презентации.
